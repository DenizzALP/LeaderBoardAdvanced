# Leaderboard Web App

A simple and interactive leaderboard application built using HTML, CSS, and JavaScript. Users can add players with their name, surname, country, and score. The leaderboard updates dynamically and allows you to increase/decrease a player's score or remove them from the list.

## Features

- Add new players with name, last name, country, and score
- Automatically sorts players by score in descending order
- Increase or decrease a player's score by 5
- Delete a player from the leaderboard
- Displays current date and time for each entry
- Input validation to ensure all fields are filled

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome for icons

## Getting Started

1. Clone the repository or download the files.

    ```bash
    git clone https://github.com/DenizzALP/LeaderBoardAdvanced.git
    ```

2. Open `index.html` in your browser.
3. Start adding players and managing the leaderboard.

## File Structure

- `index.html`: Main HTML structure
- `style.css`: Styles for layout and components
- `script.js`: Logic for functionality (add, delete, update scores, sort)
